# 資料庫設計 — TradingIocAOP

> 衝突以 [開發專案規格書.md](../開發專案規格書.md) 第 5 章為準。  
> 規範：EngineeringOS `knowledge/database-design.md`  
> 僅 `trading-app` 使用 JPA；`common`／`mini-ioc` 無 DB。

## 1. 存取鏈

```text
OrderController → OrderService (@Transactional) → OrderRepository → H2
```

## 2. 資料表

| 表 | 用途 | 重要欄位 |
|----|------|----------|
| `orders` | 成交訂單 | PK `order_id`；`client_order_id`；symbol／side／quantity／`executed_price`／status／`created_at` |

風控拒絕不落庫（見整合測試 RISK_INT_001）。

## 3. Entity 對照

| Entity | 表 |
|--------|-----|
| `OrderEntity` | `orders` |

## 4. 環境

| Profile | DB | 說明 |
|---------|-----|------|
| 預設／test | H2 `MODE=PostgreSQL` | in-memory |

## 5. SQL 驗證

```sql
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_NAME = 'ORDERS';
-- 或 H2 Console: http://localhost:8080/h2-console
```
