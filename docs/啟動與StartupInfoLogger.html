啟動與 StartupInfoLogger

ApplicationReadyEvent → Console 連結框 · IoC／AOP／Swagger／H2 怎麼用

codeGraphic 初學者說明書 規格書

1. 一句話

TradingApplication 啟動 → Spring IoC＋AOP 就緒 → Tomcat :8080 → ApplicationReadyEvent → StartupInfoLogger 依 startup.info.* 印框。

2. 怎麼啟動

入口操作
IntelliJ執行 TradingApplication（模組 trading-app）
Gradle.\gradlew.bat :trading-app:bootRun
手刻對照.\gradlew.bat :mini-ioc:run

關閉輸出：YAML 設 startup.info.enabled: false。

3. Console 會印什麼

  • Actuator health／info
  • Swagger UI、OpenAPI JSON
  • H2 Console＋JDBC（帳號 sa、密碼 password）
  • 切面報告 /api/v1/aspects/report
  • 靜態 Vue Demo /
  • mini-ioc 對照指令提示

實作：trading-app/.../config/StartupInfoLogger.java

4. Runtime 流程

sequenceDiagram participant Dev as 開發者 participant Boot as bootRun / IntelliJ participant Main as TradingApplication participant Ctx as ApplicationContext participant Tomcat as Tomcat :8080 participant SIL as StartupInfoLogger Dev->>Boot: Run Boot->>Main: main() Main->>Ctx: 建 Bean + AOP 代理 Ctx->>Tomcat: 開埠 Tomcat->>SIL: ApplicationReadyEvent SIL->>SIL: 讀 startup.info.* SIL-->>Dev: Console 連結框

5. 相關技術怎麼用

5.1 ApplicationReadyEvent

YAML 載入、Bean 建立、Tomcat 開埠之後才發事件。此時印 URL 才保證可連。

5.2 Environment／startup.info.*

埠、H2、Swagger、前台型態都從 YAML 讀，改設定不必改 Java。本專案：frontend: static、auth: false。

5.3 IoC：Spring vs mini-ioc

Spring trading-app手刻 mini-ioc
ApplicationContextMiniApplicationContext
@Component + 建構子注入掃描 + 建構子參數解析
Ready 後印 HTTP 入口run 後印 [LOG]/[TIMING]

5.4 AOP 驗證

  1. POST /api/v1/orders 下單
  2. GET /api/v1/aspects/report 看 logs／timings／audits
  3. GET /api/v1/pricing/{symbol} 兩次 → 觀察 cacheHits

順序：Logging(10) → Performance(20) → Exception(30) → Retry(40) → Cache(50) → Audit(60)。

5.5 Swagger

開 http://localhost:8080/swagger-ui.html → Try it out。

5.6 H2 Console

  1. 開 /h2-console
  2. JDBC 貼 Console 框內字串
  3. sa / password → SELECT * FROM ORDERS;

記憶體庫：重啟應用後資料清空。

6. 5 分鐘上手

  1. 啟動 trading-app，確認 Console 框
  2. 開 Swagger 或 / 下單
  3. 開切面報告確認有資料
  4. （選）H2 查表；（選）跑 mini-ioc
