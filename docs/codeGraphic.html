5 分鐘上手 — IntelliJ / bootRun

  • 執行 TradingApplication 或 .\gradlew.bat :trading-app:bootRun。
  • 啟動成功後 Console 會印連結框（StartupInfoLogger）。
  • 開 Swagger 或同埠 / Demo 下單 → 再看切面報告。
  • 手刻對照：另開 .\gradlew.bat :mini-ioc:run。

mini-ioc — 手刻 IoC/AOP

  • MiniApplicationContext 手刻容器。
  • JDK 動態代理實作 AOP 攔截。
  • common 純 POJO 零框架依賴。
  • 執行：.\gradlew.bat :mini-ioc:run。
flowchart TB APP[MiniApplicationContext] APP --> BEAN[Bean definitions] BEAN --> PROXY[JDK Dynamic Proxy] PROXY --> ADV[Advice interceptors] ADV --> TARGET[Target method]

對照 trading-app 的 Spring 原生 DI/AOP。

六大切面 — @Order 鏈

  • Logging(10) → Performance(20) → Exception(30)。
  • Retry(40) → Cache(50) → Audit(60)。
  • GET /api/v1/aspects/report 觀測切面。
  • AspectRecorder 記錄每次攔截。
flowchart LR L[Logging 10] --> P[Performance 20] P --> E[Exception 30] E --> R[Retry 40] R --> C[Cache 50] C --> A[Audit 60] A --> M[Method body]

Audit 為 @AfterReturning，在方法本體之後。

下單流程 — 風控到通知

  • 風控 → 報價（Cache 第二次命中）→ 落庫 FILLED。
  • NotificationService 經 Retry 切面。
  • OrderRepository → H2 orders 表。
  • Port 8080 trading-app。
sequenceDiagram participant C as Client participant OC as OrderController participant AOP as AOP chain participant OS as OrderService participant DB as H2 C->>OC: POST orders OC->>AOP: intercept AOP->>OS: placeOrder OS->>DB: save FILLED OS-->>C: 201

Pricing：GET /api/v1/pricing/{symbol} 示範 Cache。

模組 — Gradle 三模組

  • common ← mini-ioc；common ← trading-app。
  • mini-ioc 與 trading-app 互不相依。
  • trading-app：api / application / aspect / infrastructure。
  • 驗證：gradlew checkAll。
