啟動與位址

啟動.\gradlew.bat :trading-app:bootRun（mini-ioc 為純教學模組，無 HTTP）
Port8080（trading-app）
OpenAPI JSONhttp://localhost:8080/v3/api-docs
Swagger UIhttp://localhost:8080/swagger-ui.html
H2 Consolehttp://localhost:8080/h2-console（JDBC jdbc:h2:mem:tradingdb，帳號 sa，密碼 password）
驗證.\scripts\check.ps1 → gradlew checkAll

API 分組（實際 Controller）

  • Orders：POST /api/v1/orders、GET /api/v1/orders/{orderId}、GET /api/v1/orders
  • Pricing：GET /api/v1/pricing/{symbol}
  • Aspects：GET /api/v1/aspects/report（六大切面觸發統計觀測）

認證與範例流程

  • 無認證（無 Spring Security／JWT），啟動後可直接呼叫。
  • 教學重點：每次呼叫業務 API 都會觸發日誌、計時、驗證等切面。
  • 範例：POST /api/v1/orders 下單 → GET /api/v1/pricing/{symbol} 查價 → GET /api/v1/aspects/report 看六大切面攔截統計。

本頁載入 http://localhost:8080/v3/api-docs，請先啟動 trading-app。若以 file:// 直接開啟本頁而無法載入， 請改用 http://localhost:8080/swagger-ui.html，或在 docs 目錄啟一個靜態伺服器（例如 python -m http.server）。
