# TradingIocAOP 註解規範

> 權威：EngineeringOS `eos-minimal/knowledge/comments.md` @ 0.1.5  
> 本專案宣告：`comment_verbosity: detailed`

## 為什麼是 detailed？

本專案是 **IoC／AOP 教學雙軌**，註解要讓初學者看懂：

1. **【職責】** 這個型別／方法在業務或框架上做什麼  
2. **【技巧】** 用了哪個框架／API／模式（建構子注入、JDK Proxy、`@Around`／`@Order`…）  
3. **【概念】** 為什麼這樣寫、和「自己 new／把日誌寫進業務方法」差在哪  

對照兩條學習軌：

| 模組 | 教學重點 |
|------|----------|
| `mini-ioc` | 手刻 IoC 容器 + 攔截器鏈（控制反轉、JDK 動態代理） |
| `trading-app` | Spring Boot + 六大切面（Logging／Performance／Exception／Retry／Cache／Audit） |

一般業務專案請改為 `brief`，避免註解過長。切換方式見公版 §7。

## 套用範圍

| 路徑 | 深度 |
|------|------|
| `common/src/main/java/**` | detailed |
| `mini-ioc/src/main/java/**` | detailed（容器／攔截器／註解尤重） |
| `trading-app/src/main/java/**` | detailed（Aspect 必寫橫切關注點） |
| `*/src/test/java/**` | detailed（含 CASE／Given-When-Then；可加【技巧驗證】） |
| `scripts/*.ps1` | 檔頭用途／何時跑／成功標準 |
