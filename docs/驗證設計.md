# 驗證設計 — TradingIocAOP

> 衝突以 [開發專案規格書.md](../開發專案規格書.md)、[API規格書.md](../API規格書.md) 為準。  
> 規範：EngineeringOS `knowledge/validation-design.md`  
> 無 Spring Security。

## 1. 分層

| 層 | 機制 | 說明 |
|----|------|------|
| DTO | `@Valid` `PlaceOrderRequest` | 缺欄位／quantity≤0 等 → 400 `VALIDATION_FAILED` |
| Application | `RiskService.check()` | 數量／名目上限等 → 422 `RISK_REJECTED`（R002／R003） |
| HTTP 錯誤 | `GlobalExceptionHandler` | 對齊 API 錯誤碼表 |
| AOP | `ExceptionAspect` | 記錄拋出；不改業務規則 |

## 2. 錯誤碼（摘要）

| HTTP | errorCode | 情境 |
|------|-----------|------|
| 400 | VALIDATION_FAILED | Bean Validation |
| 422 | RISK_REJECTED | R002 數量上限；R003 名目金額上限 |
| 404 | （查無訂單） | `GET /orders/{id}` |

完整表見 [API規格書.md](../API規格書.md)。

## 3. 不在範圍

- 認證授權、冪等 Header（本專案未實作 Idempotency-Key）。
